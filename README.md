# TNG 日常开销

一个纯前端的静态记账网页(单个 `index.html`),用来记录 TNG eWallet 的日常进出。

## 功能
- 记一笔(支出/收入),日期、时间可修改,备注可选
- 点任意一笔可编辑或删除
- 日历按月查看,可选单日或日期区间看合计
- 月报卡片(点"分享给家人"),可截图,或点"复制链接"生成加密链接发给家人

## 使用
直接用浏览器打开 `index.html`,或部署到任意静态托管(GitHub Pages、Netlify、Cloudflare Pages)。

## 数据存储
在 Claude 之外运行时,数据保存在浏览器本地(localStorage),不会同步到其他设备。

## 加密分享链接
点月报卡片里的"复制链接"并设置密码后,当月数据会用 PBKDF2 + AES-GCM 在浏览器内加密,放进链接的 `#s=...` 部分(不会发送到服务器,无需后端)。家人打开链接、输入密码才能看到只读月报。

- 链接是数据生成时的快照,不会自动更新;有新记录需重新生成
- 链接和密码请分开发送;密码建议 8 位以上(数据就在链接里,弱密码可被离线暴力破解)
- 需在 https 或 localhost 下使用(GitHub Pages 满足)
